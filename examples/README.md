# Independent native examples

These geometric sources are toolkit fixtures, not PixelSpark artwork. The four Aseprite
files remain editable. author.lua and author_motion.gd create only missing sources;
they do not replace artist edits. Recipes are relative to the toolkit workspace root.

Native acceptance copies, builds, edits and reviews examples in a temporary workspace.
The 320×180 viewport deliberately differs from PixelSpark. Authored motion is retained;
generated scenes/textures/import caches are excluded from distribution.
